# HONOR 90 Pro：Gate 0验收单

目标为作者的HONOR 90 Pro（ARM64）。以下是待执行步骤，不是已通过的结果。APK是技术验证壳，界面与生产聊天数据模型均未定稿。

## 安装前

在手机“设置→关于手机”记录Android/MagicOS版本、型号和内存。记录APK文件名、来源、SHA256、版本和对应代码commit。本地Release探针使用生成的DEBUG测试证书；EAS以后使用独立签名，同package不同签名不能直接覆盖安装。卸载会删除本地数据，禁止用卸载或清库修复正式用户数据。

只对本项目测试APK临时允许安装来源。安装完成关闭安装来源权限。APK含内置Hermes bundle，冷启动和本地数据测试不需要Expo Go或开发服务器。

## 基础运行与本地数据

1. 安装后关闭网络，冷启动“Mobile AI RP · Gate 0”，记录是否出现首页、报错或崩溃；录屏不含私密信息。
2. 点击“准备 1000 条合成消息”，应先显示最新50条。点击“加载更早的50条”直到1000条，观察编号、重复/遗漏、长CJK文本和滚动卡顿，记录每次分页显示耗时。页面单次ms不是正式P95。
3. 再点准备，数据不应重复。杀进程后重开，应显示已持久化的最新50条；再次分页仍能取回更早消息。
4. 点击“开始模拟流”，观察逐段显示；在完成前点击“停止生成”，之后不再累加。此项是进程内mock，只验证交互，不算网络验收。
5. 在相同条件分别进行20次冷热启动，记录原始耗时；正式FPS/内存以Android profiler/系统工具取样，不凭肉眼填写数值。

## 真正的网络流

进入“打开网络与卡片验证”。需要设备可访问且受信任证书有效的HTTPS SSE模拟服务，Base URL形如https://your-mock.example/v1，不含Key、query或fragment。不要输入真实聊天或令牌；本页只发固定合成请求。

仓库`pnpm mock:sse`仅监听开发机loopback8787，不会自动成为手机可访问的HTTPS服务。开发者应在受控网络准备HTTPS入口并核对服务日志与设备时间，不能把任意公共站点当作模拟接口。Base URL后自动请求POST /chat/completions，服务须返回text/event-stream及data: [DONE]。

记录完整收流、途中取消、取消后重新开始、切换页面、Wi-Fi/移动网络切换及中断时的结果。取消后文本应停止累加，旧请求不应污染新请求；记录错误码和复现步骤。无设备实际请求和服务端对应证据不能勾选网络通过。

## 文件读取

点击“选择本地JSON / PNG卡片”，选择有权使用的V2/V3卡，记录来源/许可/hash。成功后显示名字、spec与警告；取消选择不应报成功。对同一文件重复选择、错误JSON、超限文件分别记录结果。选择只读取临时副本与元数据，不应发网络请求；不会导入生产数据库或执行宏/脚本。不得上传含私密角色/聊天的原始卡作为公共Issue附件。
