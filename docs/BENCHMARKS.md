# 性能与评估：待验证假设

没有真机结果，不发布性能领先或“快X倍”结论。固定相同Android硬件与release APK；记录版本/commit/热状态/环境与原始样本。100/1000/5000/10000消息，10%超长、CJK/英文、图片/无图，编辑/分支场景分别测。

| 指标                   | 初始目标（非实测）     | 记录方法                       |
| ---------------------- | ---------------------- | ------------------------------ |
| 1k会话打开至最新可交互 | P95 <1.5s              | 冷热分开，各20次               |
| 5k持续滚动             | 中位FPS >=50，无长白屏 | 平台profiler，固定滚动脚本     |
| 50条DB分页             | P95 <100ms             | 固定数据与native设备           |
| 1k/5k/10k内存          | 不随总历史近线性上涨   | RSS/JS/native内存、加载页数    |
| 流式取消               | 操作后立刻停止UI累加   | mock网络、弱网、另一会话完整性 |
| 断网/杀进程            | 已保存消息无丢失       | 20轮恢复、未完成状态           |
| 导入导出               | 标准字段不丢失         | golden、round-trip与损失报告   |

当前host SQL只验证正确性/索引，不把host耗时当手机SLO。Lab显示单次page毫秒只供诊断，不是正式P95报告。缺统一条件的ChatterUI/RisuAI/SillyTavern只作定性参考，自身回归优先。

Gate3的RP-Consistency是项目自研基准，不是社区标准：50–100故事、100/500/1000消息、A最近/B固定摘要/C关键词FTS/D事实时间分支过滤/E未来语义；固定底模参数和相近token预算，报告准确率/矛盾率/引用准确率/成本/延迟/置信区间及失败案例，人工盲评抽查，不预设D/E获胜。LongMemEval/LoCoMo的引用/许可/子集范围另记录。
