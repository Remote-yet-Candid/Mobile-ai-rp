# 产品范围与设计基线

以 [设计v1.0原文](design/source-v1.0.md) 为总体依据。Android优先、离线数据优先、BYOK、无官方账号/自建后端，纯TS RP Core可单独复用。离线可访问本地数据不表示断网仍能调用远程LLM。

## P0 / v0.1（Gate 1）

独立APK/升级保留数据；多endpoint/model/Key/参数配置与连接测试；单角色聊天、流式/取消/重试；本地角色创建、V2/V3 JSON和优先PNG导入/无损导出；分页/搜索/复制/编辑/重新生成/候选回复/时间状态；SQLite迁移与不含Key的完整导出恢复；最小Prompt Inspector（分段/优先级/token估计/请求预览默认不持久化）；字体/暗色/键盘/长按/可访问性；单元/集成与真实Android验收。

## P1 / v0.2（Gate 2）

可追踪世界书常量/关键词/范围/优先级/预算子集；正式不可变分支DAG与跨分支隔离；事实/事件/关系/阶段状态，候选提取确认拒绝修正、时间有效性与来源回链；本地FTS及中文短查询评估；SillyTavern JSONL及未知字段迁移；完整Inspector；CHARX资源与CJK/多模态兼容。

## P2 / v0.3+（反馈后决策）

Anthropic/Gemini/OpenRouter特色/补全/缓存/停止词/推理约束，多角色发言控制，可选向量/混合检索/事实图谱，Web/Desktop，权限沙箱插件SDK，语音/TTS/图像/VN，可选独立GGUF native推理。全部保留，不提前作为首发依赖。

## 首发不做

官方转发/付费模型平台、注册/云同步、社交网络、商店、任意JS插件、100%SillyTavern插件或任意Provider兼容、基础LLM训练。

## 当前迭代

作者已授权并行推进 Gate 1 v0.1 单角色交互原型，Gate 0 遗留设备/安全事项独立跟踪。复用已有 Core/Provider/codec；正式角色和聊天使用独立生产 schema，技术验证入口保留为 /lab。正式发布安全门槛不变。世界书、长期记忆、完整宏/插件和复杂迁移仍按后续规划执行。
